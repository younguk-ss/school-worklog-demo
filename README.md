# 학교 업무일지 & 공유 달력 (데모 버전)

교직원이 함께 쓰는 학교 업무일지 웹 앱입니다. 구글 앱스 스크립트로 **무료로** 배포하고, 선생님들은 **로그인 없이 주소만 열면** 바로 씁니다.

- 📅 공유 달력 · ✨ AI 업무 입력기 · 🤖 AI 챗봇 · AI 주간/월간 요약
- 🗓️ 주간 업무계획 · 📋 월중계획 · 📥 계획 구글 시트 만들기
- 📝 교육활동 성찰 게시판(엑셀 보고서)
- 🗂️ 온라인 교무실 — 부서별 자료를 구글 드라이브에 올리고 일정에 연결
- 🍱 급식 · 📚 시간표 — 나이스(NEIS)에서 우리 학교 정보를 자동으로 불러옴 (초·중·고)

## 시작하기

👉 **[사용 방법(선생님용)](사용%20방법(선생님용).md)** 을 순서대로 따라 하세요. 30분 정도 걸립니다.

1. 파일 3개(`code.gs`, `index.html`, `appsscript.json`)를 [script.google.com](https://script.google.com) 새 프로젝트에 붙여넣기
2. `setupDemo` 한 번 실행 → 웹 앱으로 배포(실행: 나 / 액세스: 모든 사용자)
3. 앱의 **⚙ 관리 정보 → 처음 설정**에서 나이스 API 키, 우리 학교, Gemini API 키 넣기
4. 학교에서 계속 쓰려면 우리 학교 Firebase 데이터베이스를 만들어 연결 (무료)

## 코드를 고치려면

AI 코딩 도우미에게 **[AI 인계 지침서](AI%20인계%20지침서.md)** 를 먼저 읽게 한 뒤 요청하세요. 구조, 지켜야 할 규칙, 로컬 시험 방법이 들어 있습니다.

## 주의

- 로그인 없이 쓰는 앱이라 **주소를 아는 사람은 누구나 내용을 보고 고칠 수 있습니다.** 주소는 교직원끼리만 나누고, 학생 개인정보·민감한 정보는 넣지 마세요.
- API 키는 코드에 적지 말고 앱의 「처음 설정」에서 넣으세요(스크립트 속성에 저장됩니다).
